# Spira · Atlante della quiete

Sette stampe in movimento, ognuna con il suo colore e il suo registro sonoro. Tocca una tinta per cambiare opera. Ascolta abilita la sintesi locale, con tre timbri e volume regolabile. Immergiti estende il disegno a tutta la finestra. Il pulsante nell’angolo della tavola ferma il movimento indipendentemente dal suono.

## Pubblica
1. Estrai lo ZIP e carica i file nella radice del repository GitHub. Il file index.html deve trovarsi accanto a spira.js e style.css.
2. In Settings → Pages scegli Deploy from a branch, quindi main e / (root). Salva e attendi la pubblicazione.
3. Apri l’indirizzo HTTPS di Pages. In @BotFather imposta questo indirizzo per la Main Mini App o il pulsante menu del bot.
4. Apri dal bot su Android, ruota lo schermo e prova la modalità immersiva. Il client Telegram gestisce le proprie barre di sistema.
